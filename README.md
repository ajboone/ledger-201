# Ledger 201

Ledger 201 is a restaurant expense and purchasing management application. It
is designed to help restaurants organize vendor information and track the
financial activity involved in purchasing supplies.

The application consists of:

- A React and TypeScript frontend for the user interface
- A FastAPI and SQLAlchemy backend for the API and data management
- A SQLite database for local data storage

More detailed setup and run instructions are available in the `frontend` and
`backend` README files.
