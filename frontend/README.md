# Running the Frontend

In order to run the frontend of this project, ensure you are in the frontend folder and run the following commands in your terminal:

Install dependencies:

```
npm install
```

Then run the app:

```
npm run dev
```

The app should then be available to view in browser at `http://localhost:5173/`
